Currency & Exchange Rate

USD values use the manually maintained IDR/USD rate below. Existing transaction snapshots are never rewritten when you update the rate.

How conversion works

Current USD asset value = current IDR asset value ÷ current exchange rate. Each transaction stores the exchange rate in effect when it was recorded, so past entries remain auditable.

Price Data Management

Add a new market price record to the historical index. The record is saved locally and can be exported as a backup.

For dates with existing records, the newest entry is used for that date. The transaction ledger stores its own price snapshot and will not change if a market record is edited or added.
